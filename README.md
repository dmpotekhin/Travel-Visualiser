# 🌍 Travel Visualizer

Локальное веб-приложение для визуализации и аналитики путешествий. Вводите
маршрут строкой или загружаете свою таблицу CSV/Excel — приложение строит карту
с анимацией движения по маршруту, раскрашивает сегменты по типу транспорта и
считает статистику (общий пробег, экваторы, расстояние до Луны, топ-города,
доли транспорта и т.д.).

Стек: **Python + FastAPI** (бэкенд) · **MapLibre GL JS** (карта) · **SQLite**
(история). Геокодирование и маршруты — через **HERE API** (опционально), с
полноценным офлайн-фолбэком на **Nominatim + формулу Гаверсина**.

---

## Быстрый старт

```bash
cd ~/projects/travel-visualizer
./scripts/start.sh
```

Скрипт создаст venv, поставит зависимости и запустит сервер. Откройте
**http://127.0.0.1:8000**

> Альтернатива без скрипта:
> ```bash
> python3 -m venv .venv && source .venv/bin/activate
> pip install -r requirements.txt
> python main.py
> ```

## Конфигурация (HERE API — опционально)

Без ключа приложение полностью работает: геокодирование через Nominatim,
расстояния — по дуге большого круга (Гаверсин). Для реальных дорожных/ЖД
расстояний и геометрии добавьте бесплатный ключ HERE:

```bash
cp .env.example .env
# в .env укажите:  HERE_API_KEY=ваш_ключ
```

Ключ бесплатного тарифа — на https://developer.here.com/. Ключ **не зашивается**
в код, хранится только в `.env` (файл в `.gitignore`).

## Использование

### 1. Один маршрут (карта + анимация)

Введите города через дефис, например `Санкт-Петербург – Москва – Пекин`, и
нажмите «Показать анимацию». Откроется карта: сегменты окрашены по типу
транспорта, маркер движется вдоль маршрута, слева — инфоблок (км, экваторы,
доля транспорта, время).

Тип транспорта указывается в скобках после города — им помечается **следующий
за ним** сегмент:

```
Санкт-Петербург [поезд] – Москва [самолёт] – Пекин
```

Если тип не указан — определяется по ключевым словам, иначе по умолчанию **авто**.

### 2. Загрузка таблицы (CSV / Excel)

Кнопка «Загрузить таблицу». Ожидаемые колонки (имена определяются по
ключевым словам, регистр не важен):

| Колонка | Ключевые слова |
|---|---|
| Маршрут (кратко) | `маршрут`, `route` |
| Общее расстояние, км | `расстоян`, `км`, `distance` (опционально) |
| Примечания | `примечан`, `note` (опционально) |
| Год | `год`, `year` (опционально) |

После обработки вы увидите сравнение «ваша оценка / расчёт», сводную
аналитику и список ссылок на карты каждого маршрута.

Готовый пример: `data/sample_routes.csv`.

### 3. Аналитика

На главной странице автоматически считаются:

- общий пробег (км и мили);
- число экваторов (км / 40 075) и доля пути до Луны (км / 384 400);
- средний пробег на маршрут;
- распределение по годам и по типам транспорта (графики);
- топ-5 самых длинных маршрутов и топ-5 частых городов;
- оценка времени в пути (самолёт 850 км/ч, поезд 80 км/ч, авто 90 км/ч).

## API

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/animate` | строка маршрута (form или JSON `{"route": ...}`) → HTML-карта с анимацией |
| `POST` | `/upload` | файл CSV/Excel (multipart) → сводная аналитика + список карт |
| `GET`  | `/stats` | общая статистика по всем маршрутам |
| `GET`  | `/history` | список всех маршрутов с датами |
| `GET`  | `/map/{id}` | HTML-карта сохранённого маршрута |
| `GET`  | `/api/geojson/{id}` | маршрут с GeoJSON (для карты) |
| `GET`  | `/health` | статус сервера и наличие HERE-ключа |

## Типы транспорта и ключевые слова

| Тип | Скорость | Ключевые слова |
|---|---|---|
| 🛩 Самолёт | 850 км/ч | самолёт, авиа, перелёт, flight, plane, air |
| 🚆 Поезд | 80 км/ч | поезд, ж/д, железнодорожный, rail, train |
| 🚗 Авто | 90 км/ч | авто, автомобиль, машина, car, drive, taxi |
| 🚌 Автобус | 70 км/ч | автобус, bus, coach |
| ⛴ Паром | 35 км/ч | паром, корабль, круиз, ferry, ship |
| 🚲 Велосипед | 18 км/ч | велосипед, вело, bike |
| 🚶 Пешком | 5 км/ч | пешком, walk, треккинг |

## Как это работает

1. Строка разбивается на сегменты (город → город).
2. Каждый город геокодируется: **кэш → HERE → Nominatim**.
3. Для каждого сегмента считается геометрия + расстояние + время:
   - **воздух** — всегда дуга большого круга (авиалиний в открытом доступе нет);
   - **наземный транспорт + HERE-ключ** — реальные дороги/ЖД через HERE
     Routing v8 (геометрия + точное расстояние), фолбэк на Matrix API;
   - **без ключа** — расстояние по Гаверсину + дуга большого круга.
4. Сегменты собираются в один GeoJSON с атрибутами (транспорт, цвет, км, время).
5. Маршрут сохраняется в SQLite (`data/travel.db`) для аналитики.

## Ограничения и примечания

- Без HERE-ключа расстояния считаются **по прямой** (дуга большого круга),
  поэтому наземные сегменты могут быть короче реальных дорожных. С ключом
  используются реальные расстояния/геометрия.
- Авиа-сегменты всегда прямые (публичных авиалиний нет) — это допущение.
- Геокодирование неизвестных городов требует интернета (Nominatim), но ~60
  крупных городов закэшированы и работают офлайн.
- История хранится локально в `data/travel.db`; чтобы начать с чистого листа,
  удалите этот файл.
