# 🌍 Travel Visualizer

**Локальное приложение для визуализации и аналитики путешествий.** Вводите
маршрут строкой или загружаете свою таблицу CSV/Excel — приложение строит
интерактивную карту с анимацией движения по маршруту, раскрашивает сегменты по
типу транспорта и считает статистику: общий пробег, экваторы, расстояние до
Луны, топ городов, доли транспорта и время в пути.

## Что это

Персональный инструмент для тех, кто ведёт учёт своих поездок. Вместо таблицы с
сухими цифрами — карта, где видно весь путь, цвет сегмента означает тип
транспорта, а маркер «летит» вдоль маршрута. Сверху — привычные «вау-метрики»:
сколько раз вы обогнули экватор и какую долю пути до Луны уже проехали.

## Возможности

- **Карта + анимация** — маршрут на MapLibre GL JS, сегменты окрашены по типу
  транспорта, маркер движется вдоль линии (пауза / заново / прогресс).
- **Ввод строкой** — `Санкт-Петербург – Москва – Пекин`, с опциональным типом
  транспорта на каждом участке: `Москва [поезд] – Пекин [самолёт]`.
- **Загрузка CSV/Excel** — массовая обработка таблицы, сравнение «ваша оценка /
  расчёт» и ссылки на карту каждого маршрута.
- **Аналитика** — общий пробег (км/мили), экваторы, путь до Луны, среднее на
  маршрут, распределение по годам и транспорту, топ-5 маршрутов и городов,
  оценка времени в пути.
- **История** — все маршруты хранятся в SQLite, каждому доступна отдельная
  карта по ссылке `/map/{id}`.
- **Работает без ключей** — HERE API опционален; без него используется
  Nominatim + формула Гаверсина.

## Быстрый старт

```bash
cd travel-visualizer
./scripts/start.sh
```

Скрипт создаст виртуальное окружение, установит зависимости и запустит сервер.
Откройте **http://127.0.0.1:8000**

Без скрипта:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Требования: Python 3.11+ (на macOS и Linux работает из коробки).

## Конфигурация — HERE API (опционально)

По умолчанию приложение полностью работоспособно: геокодирование через
Nominatim, расстояния — по дуге большого круга (Гаверсин). Чтобы получать
реальные дорожные и железнодорожные расстояния и геометрию, добавьте бесплатный
ключ HERE:

```bash
cp .env.example .env
# отредактируйте .env:
#   HERE_API_KEY=ваш_ключ
```

Ключ бесплатного тарифа — на [developer.here.com](https://developer.here.com/).
Ключ **не зашивается** в код: он живёт только в `.env` (файл в `.gitignore`).

## Использование

### Одиночный маршрут

Введите города через дефис и нажмите «Показать анимацию». Тип транспорта
указывается в скобках после города — им помечается **следующий за ним** сегмент:

```
Санкт-Петербург [поезд] – Москва [самолёт] – Пекин
```

Если тип не указан — определяется по ключевым словам (`на поезде`, `самолётом`,
`на авто` …), иначе по умолчанию **авто**.

### Загрузка таблицы

Кнопка «Загрузить таблицу». Колонки определяются по заголовкам (регистр не
важен):

| Колонка | Распознаётся по |
|---|---|
| Маршрут (кратко) | `маршрут`, `route` |
| Общее расстояние, км | `расстоян`, `км`, `distance` *(опционально)* |
| Примечания | `примечан`, `note` *(опционально)* |
| Год | `год`, `year` *(опционально)* |

Пример файла — `data/sample_routes.csv`.

## API

| Метод | Путь | Описание |
|---|---|---|
| `POST` | `/animate` | строка маршрута (form или JSON `{"route": "..."}`) → HTML-карта с анимацией |
| `POST` | `/upload` | файл CSV/Excel (multipart) → сводная аналитика + список карт |
| `GET` | `/stats` | общая статистика по всем маршрутам |
| `GET` | `/history` | список всех маршрутов с датами |
| `GET` | `/map/{id}` | HTML-карта сохранённого маршрута |
| `GET` | `/api/geojson/{id}` | маршрут с GeoJSON |
| `GET` | `/health` | статус и наличие HERE-ключа |

## Типы транспорта

| Тип | Средняя скорость | Ключевые слова |
|---|---|---|
| 🛩 Самолёт | 850 км/ч | самолёт, авиа, перелёт, flight, plane, air |
| 🚆 Поезд | 80 км/ч | поезд, ж/д, железнодорожный, rail, train |
| 🚗 Авто | 90 км/ч | авто, автомобиль, машина, car, drive, taxi |
| 🚌 Автобус | 70 км/ч | автобус, bus, coach |
| ⛴ Паром | 35 км/ч | паром, корабль, круиз, ferry, ship |
| 🚲 Велосипед | 18 км/ч | велосипед, вело, bike |
| 🚶 Пешком | 5 км/ч | пешком, walk, треккинг |

## Как это работает

```
маршрут ("СПб – Москва – Пекин")
        │  разбиение на сегменты (город → город)
        ▼
геокодирование городов:  кэш → HERE → Nominatim
        │
        ▼
каждый сегмент: геометрия + расстояние + время
   ├─ воздух        → дуга большого круга (авиалиний в открытом доступе нет)
   ├─ наземный + HERE → реальные дороги/ЖД (HERE Routing v8), фолбэк Matrix API
   └─ без ключа     → Гаверсин + дуга большого круга
        │
        ▼
GeoJSON FeatureCollection (транспорт, цвет, км, время)
        │
        ▼
сохранение в SQLite (data/travel.db)  →  аналитика и история
```

## Ограничения

- Без HERE-ключа расстояния считаются **по прямой** (дуга большого круга),
  поэтому наземные сегменты могут быть короче реальных дорожных. С ключом —
  реальные расстояния и геометрия.
- Авиа-сегменты всегда по прямой — публичных авиалиний нет, это допущение.
- Геокодирование незнакомых городов требует интернета (Nominatim); ~60 крупных
  городов закэшированы и работают офлайн.
- История хранится локально в `data/travel.db`; чтобы начать с чистого листа,
  удалите файл.
